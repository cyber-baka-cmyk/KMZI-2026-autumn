# Криптографические методы защиты информации

Репозиторий содержит практические материалы, исходный код и отчеты по лабораторным работам в рамках учебной дисциплины «Криптографические методы защиты информации» для студентов дневной формы получения высшего образования специальности 6-05-0611-03 «Искусственный интеллект» (Брестский государственный технический университет). 

## Направленность и цель курса
Целью преподавания дисциплины является формирование у студентов глубоких теоретических знаний, строгой математической базы и практических инженерных навыков в области современной, сетевой и постквантовой криптографии, протоколов конфиденциальности, распределенных реестров и криптографических методов защиты систем искусственного интеллекта.

Курс охватывает три ключевых тематических блока:

1. Фундаментальная и классическая криптография: математические основы симметричных шифров (AES, ГОСТ/БелТ) и полей Галуа, теория чисел и асимметричные системы (RSA, CRT, эллиптические кривые и ECC-протоколы), схемы цифровых подписей (DSA, Schnorr, ECDSA, Ed25519, национальные стандарты СТБ/ГОСТ), защита от атак по побочным каналам и Constant-time программирование.
2. Сетевая криптография, ZKP и постквантовая безопасность: инфраструктура открытых ключей (PKI, ГосСУОК/ГУЦ) и протоколы TLS 1.3, сетевая и беспроводная безопасность (DNSSEC, IPsec, WPA3, VPN), доказательства с нулевым разглашением (ZKP, zk-SNARKs), а также стандарты постквантовой криптографии (PQC на решетках — Kyber/Dilithium, кодовая криптография и подписи SPHINCS+).
3. Распределенные системы, приватность и криптографическая защита ИИ: блокчейн-технологии, алгоритмы консенсуса и безопасность смарт-контрактов, протоколы анонимности и ZK-Rollups, конфиденциальные вычисления через гомоморфное шифрование (FHE/CKKS) и безопасные многопартийные вычисления (SMPC), а также механизмы дифференциальной приватности (DP-SGD) для защиты данных в машинном обучении.

##  Правила сдачи лабораторных работ (через Fork & Pull Request)

Сдача всех лабораторных работ в рамках курса происходит строго через механизм **Fork**, ветвление и создание **Pull Request (PR)**. Прямые комшиты в основной репозиторий (`main`/`master`) запрещены.

### Пошаговая инструкция по сдаче:

1. Сделайте Fork основного репозитория курса на ваш личный аккаунт GitHub.
2. Клонируйте ваш форк на локальный компьютер:

```bash
git clone https://github.com/YOUR_USERNAME/repository-name.git
cd repository-name
```

3. Создайте отдельную ветку для выполнения конкретной лабораторной работы (название должно отражать суть, например lab-1-galois или lab-2-rsa):

```bash
git checkout -b lab-X-yourname
```

4. Реализуйте задание в соответствующей директории, строго соблюдая требования безопасности (отсутствие динамических контейнеров на куче, constant-time вычисления и т.д.).


5. Фиксируйте изменения понятными коммитами:
```bash
git add .
git commit -m "реализовал модуль калькулятора полей Галуа для ЛР №1"
```

6. Отправьте созданную ветку в ваш личный форк на GitHub:

```bash
git push origin lab-X-yourname
```

7. Создайте Pull Request в основной репозиторий курса:

Перейдите на страницу основного репозитория и нажмите Compare & pull request. Убедитесь, что базовой веткой (base) выбрана main, а сравниваемой (compare) — созданная вами рабочая ветка из форка.
При создании Pull Request строго соблюдайте следующий шаблон именования:

**[Лаб X] Фамилия Имя — Вариант N**
